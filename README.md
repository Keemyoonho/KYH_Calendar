# KYH Calendar

개인 일정, 버킷 리스트, 구매 목록, 가계부, 일기, 요일별 원형 시간표를 관리하는 Firebase 기반 캘린더입니다.

## 폴더 구조

- `index.html`: 화면 구조
- `css/styles.css`: 데스크톱·모바일·다크모드 디자인
- `js/theme.js`: 화면이 나타나기 전 테마 설정
- `js/app.js`: 캘린더, 가계부, Firebase 기능
- `js/timetable.js`: 요일별 24시간 원형 시간표와 독립적인 서버 저장
- `assets/`: 파비콘과 웹 앱 아이콘
- `PROJECT-BRIEF.md`: 기능 현황과 향후 계획
- `CHATGPT-PROJECT-INSTRUCTIONS.md`: 프로젝트 작업 지침

## GitHub Pages에 배포하기

이 폴더 안의 파일과 폴더를 모두 GitHub 저장소 최상단에 업로드합니다. `index.html`만 올리면 CSS, JavaScript와 아이콘이 불러와지지 않습니다.

## 수정 원칙

### 2026-10-04 시간표 개편

- 요약 카드 4개를 왼쪽 2×2로 배치하고 오른쪽에 입체 원형 시간표를 표시합니다. 모바일에서는 세로로 배치합니다.
- 요일 선택 → 시간 설정에서 할 일과 시작·종료 시각을 추가·수정·삭제합니다. 자정을 넘기는 블록도 지원하며, 같은 요일 내 시간대 중복은 방지합니다.
- 시간표는 `calendar/weeklyTimetable/{요일 번호 0~6}`에 저장합니다. 다른 기기와 같은 요일을 동시에 수정하면 덮어쓰지 않고 최신 목록 확인을 요청합니다.
- 다이어트 기록과 목표 달성 기능은 폐기했습니다. 업데이트된 화면에서 본인 로그인 및 서버 연결 후 `calendar/dietRecords`, `calendar/goalTracker`와 현재 브라우저의 `yoonho_diet_records`만 삭제합니다. 기존 월별 목표 삭제 정책도 유지됩니다.
- 이 삭제는 되돌릴 수 없습니다. 일반 일정(다이어트 분류 포함), 가계부, 일기 식단·체크리스트, 버킷 리스트, 구매 목록은 유지합니다. 다른 기기에 구버전 페이지를 열어 두었다면 모두 새로고침해야 합니다.
- `tests/timetable-ui.cjs`는 실제 개인 데이터에 접근하지 않는 가짜 서버로 삭제 범위, 보존, 시간표 CRUD, 충돌·오류 처리와 반응형 화면을 검사합니다.

1. 실제 최신 원본과 변경 이력은 GitHub에서 관리합니다.
2. 기능을 수정한 뒤에는 파일 전체를 다시 ZIP으로 묶습니다.
3. Firebase 설정과 데이터 경로를 임의로 변경하지 않습니다.
